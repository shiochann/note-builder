# note-builder｜有料ノート制作スキル

有料ノート（note / Brain）を、ヒアリングから本編・セールスレターまで一気通貫で作るClaude Code用スキルです。

## 置き方（1回だけ）

このフォルダごと、次のどちらかに置きます。

- 全プロジェクトで使う：`~/.claude/skills/note-builder/`
- 特定のフォルダだけで使う：`<そのフォルダ>/.claude/skills/note-builder/`

置いたら Claude Code で `/note-builder` と打つだけです。

## 流れ

1. ヒアリング（特典・既存ファイル・読者・知識）
2. 知識を1ファイルに統合
3. 目次と特典案を出す（ここで修正）
4. 本編を1章ずつ書く。図解の入れる場所と指示書も同時に出る
5. 本編ができてから、セールスレターの核となる主張を決める
6. 最後にセールスレター
7. （任意）Claude in Chrome で note / Brain のエディタに流し込んで、下書き保存

本編は主張に縛られず自由に書きます。主張はセールスレター専用です。
7 は Chrome拡張「Claude in Chrome」が入っていて、そのChromeで note / Brain にログイン済みのときだけ使えます。公開ボタンは押しません。

途中でやめても `_state.md` に進捗が残るので、次回 `/note-builder` で続きから再開できます。

## できあがるもの

```
<ノート名>/
  _state.md            進捗
  00_ヒアリング.md      回答の記録
  01_domain.md         まとめた知識
  02_企画書.md         特典・目次
  03_図解計画.md       図解の指示書（Canva等で作る用）
  10_本編.md           本編。これをそのままnoteに貼る
  11_主張.md           セールスレターの核となる主張
  12_セールスレター.md  販売ページ用
  20_貼り付け用/        エディタに貼るHTML（7で生成）
```

## 注意

- 数字や実績はヒアリングで答えたものしか使いません。答えていないものは【要記入】になります
- 図解は「どこに・何を入れるか」の指示書までです。画像はCanva等で作ってください
