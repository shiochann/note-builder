# 目次の型

目次は **読者が理解しやすい順・手を動かしやすい順** で組む。セールスレターの主張は持ち込まない。

## 基本構造

```
序章   このノートの進み方・読者の現在地・無料で持って帰れるもの
本編   問題 → 原因 → 解決 → 手順 → 応用 の順に
終章   読者が翌日やること・特典の案内・最後に伝えたいこと
```

## 本編の章の並べ方

| 順番 | 役割 | 内容の例 |
|---|---|---|
| 1 | 問題 | 読者が今困っていることを、本人より正確に言語化する |
| 2 | 原因 | なぜそうなるのか。世間の誤解を正す |
| 3 | 解決の全体像 | やり方の全体像。全体像の図解を入れる |
| 4〜 | 手順 | 実際にやること。1章＝1ステップ |
| 最後 | 応用・継続 | 続け方、数字の見方、つまずいたときの対処 |

これは型であって縛りではない。ユーザーが入れたい章は理由を問わず入れる。

## 章数の目安

- 5〜8章。10を超えたら統合する
- 1章の分量は3,000〜6,000字。超えるなら分ける

## 有料ラインの位置

- 基本：序章の末尾。序章で全体像を見せて、手順から有料にする
- 別案：第1章の途中。「問題」までは無料で読ませ、「原因」から有料にする
- 無料部分だけ読んでも「持って帰れるもの」を1つ置く（レターの信頼に繋がる）

## 各章につけるもの

```
### 第N章　章タイトル
- できるようになること：（1行）
- 図解（仮）：（何枚・何の図解か）
- 特典との接点：（あれば）
```

## 章タイトルのつけ方

- 「〜する」の動詞形にすると手順ものとして読みやすい（例：型を集める／投稿を量産する）
- 章番号は「第N章」で統一。節は「N-1」

## 特典の置き方

- 決まっている：終章でまとめて案内＋関係の深い章の末尾で1行触れる
- 未定：本編を読んだ読者が手を動かすときに欲しくなるものを3案。テンプレ／チェックリスト／そのまま動くスキル／実際の記録の公開／数値シート など
