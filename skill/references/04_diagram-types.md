# 図解の種類カタログ

図解は「指示書」まで作る。実際の画像はCanva等で作る前提。

## 入れる目安

- 1章に1〜3枚
- 手順・比較・全体像・Before/After・関係性 が出てきたら入れる
- 文章だけで3段落以上かかる説明は図解にする
- 表を本文に入れたくなったら図解にする（noteは表が崩れる）

## 種類

| 種類 | 向いている場面 | 要素数の目安 |
|---|---|---|
| フロー図 | 手順・毎日の流れ・処理の順番 | 3〜6ステップ |
| 全体像図 | 章の冒頭・システムの構成・登場するものの関係 | 5〜8要素 |
| 比較図（左右） | 手動と自動・Before/After・良い例と悪い例 | 左右各3〜5点 |
| マトリクス（2軸） | 優先順位・分類・どれを選ぶか | 4象限 |
| ピラミッド／階層 | 土台から積み上げるもの・レベル分け | 3〜5段 |
| タイムライン | 期間の経過・成長の記録 | 4〜6点 |
| チェックリスト | 章の末尾のまとめ・やることの確認 | 5〜8項目 |
| スクショ＋注釈 | 画面の操作・設定箇所 | 注釈3つまで |
| 概念図 | 主張そのもの・敵と味方・原因と結果 | 中心＋周辺3〜4 |

## 本文に置く目印

```
【図解N｜種類】タイトル
```

- Nはノート全体の通し番号
- 画像に差し替えるまで本文に残す

## 指示書のフォーマット（03_図解計画.md に追記）

```
## 図解N｜種類｜タイトル
- 章：第N章 N-1
- 種類：
- 入れる要素：
  - 
  - 
- キャプション：（本文で図の下に置く1行）
- サイズ：横長 1280×720（noteの本文幅に合う）
- 備考：（数字の要記入・色分けの意図など）
```

## 作るときの注意

- 1枚に伝えることは1つ。2つあるなら2枚に分ける
- 文字は最小でも24px相当。スマホで読める大きさ
- 図の中の言葉は本文の言葉と揃える（本文「型」なら図も「型」）
- 主張の図解（概念図）は序章とレターで使い回せるように作る
