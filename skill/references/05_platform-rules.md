# プラットフォーム別の記法ルール

貼り付けたときに崩れない書き方。迷ったら「使える記法を減らす」方向に倒す。

## 共通（note / Brain）

- 見出しは 章＝`#`、節＝`##`、小節＝`###`。それ以上は使わない
- **表は使わない。** 比較したいときは図解に回す
- 箇条書きのネストは1段まで
- 太字は1段落に1箇所まで。多いと効かなくなる
- 1文は60字以内を目安。スマホで読む前提で、2〜3文ごとに空行
- 引用 `>` は他人の言葉・読者の声・強調したい一文にだけ使う
- 絵文字は使わない（文体設定で許可されている場合を除く）
- リンクはURLをそのまま書く（貼ったあとカード化される）
- 章と章のあいだは空行2つ。`---` は使わない（貼ったとき二重線になることがある）

## 有料ラインの目印

```
=====ここから有料=====
```

貼るときにこの行を消して、有料ラインを設定する。

## note

- 見出しは2段階（大見出し／小見出し）しかない。`#` と `##` は大見出しに、`###` は小見出しに対応させる想定で書く。`###` が多いと階層が潰れるので、章の中は `##` を主にする
- コードブロックは使える。手順のコマンドは必ずコードブロックに入れる
- 画像は 図解の目印 `【図解N｜〜】` の位置に入れる。目印は貼ったあと消す

## Brain

- noteより記法が少ない前提で書く。コードブロックが崩れる場合は、コマンドを1行ずつ箇条書きにする
- 見出しは `#` `##` の2段までにする
- 太字・箇条書き・引用・画像 以外は使わない

## 文体

- `_state.md` の文体設定に従う。敬体/常体を混ぜない
- 一人称は固定する
- 「〜と思います」「〜かもしれません」の連続は避ける。言い切る箇所と柔らかくする箇所を分ける
