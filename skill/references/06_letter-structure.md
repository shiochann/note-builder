# セールスレターの骨格

本編が全章できてから作る。敵の設定は `02_企画書.md` の「敵と味方」をそのまま使う。

## 骨格（この順番）

```
① 冒頭に実績を数字で羅列（言える数字だけ。ないものは【要記入】）
② 無料でも持って帰れるものを宣言
③ 自己紹介と属性（読者と地続きの属性を書く）
④ 過去の失敗ストーリー（01_domain.md の失敗談から）
⑤ 転機
⑥ 生活・数字の変化
⑦ 他者の再現事例（あれば。なければ飛ばす）
⑧ 読者の悩みを言語化（本人の言葉で）
⑨ 敵を設定（既存のやり方の問題。人ではなく「やり方」）
⑩ あなたのせいじゃない
⑪ 本質の提示（＝核となる主張）
⑫ 商品と中身（完成した 10_本編.md の実際の見出しから書く）
⑬ 特典（本編のどこと繋がるかが分かるように）
⑭ 価格を出す理由・なぜこの内容を出すのか
⑮ 向いている人／買ってほしくない人
⑯ 先に正直に伝えておくこと（できないこと・向かない人）
⑰ 情緒クロージング
```

⑨の「敵の設定」が心臓部。⑪の主張は、敵を倒す手段として提示する。

## 見出しの書き方

- 見出しは `##` で統一
- 「ROAD TO 【商品名】」の節で ⑫⑬ をまとめる
- 制作メモは末尾に「## 制作メモ（公開時は削除）」として残す
